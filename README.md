## 🚀 Running Locally

### Option 1: Using the Included PowerShell Server (Active on Port 3000)
Open PowerShell in the project directory and run:
```powershell
.\server.ps1 -Port 3000
```
Then visit: [http://localhost:3000](http://localhost:3000)

### Option 2: Directly Opening in Any Browser
You can double-click `index.html` to open it directly in Google Chrome, Microsoft Edge, Safari, or Firefox without any dependencies.

## 🌐 Deploying to Vercel / Netlify / GitHub Pages

This project is 100% static and requires zero build steps or compilation:
1. **Vercel**: Import this folder and hit Deploy (Output directory: `./`).
2. **GitHub Pages**: Push this repository and enable GitHub Pages on the `main` branch.
3. **Netlify**: Drag and drop this folder directly into the Netlify dashboard.
